Architecture critique: no Codex core/TUI/provider/session/sandbox changes. The only existing runtime seams changed are lab CLI selection and a lab library export. A structured reviewer avoids parsing model-controlled plan text as authority. --jobs bounds active host intervals, including replanning after rejection; waiting hosts have a separate hard cap. Each fresh request occurs at the existing driver's quiescent review boundary. Generic model benchmarking, automated evaluation scheduling, network services, crash resume, persisted approvals and a new UI are deferred. Concurrency and shared-host/provider effects are recorded rather than silently forcing serial execution. Preserve all historical frozen suites/results.
