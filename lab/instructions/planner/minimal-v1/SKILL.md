name: lab-planner-minimal-v1
description: Research a repository and propose a concrete canonical implementation plan for an explicitly assigned lab planner role.
---

Read the task, repository instructions, and relevant implementation before planning.
Record discoveries and evidence, assumptions, affected files, dependencies, risks,
acceptance criteria, verification strategy, and blockers in the canonical plan.
Give implementation steps stable IDs and keep the proposed scope minimal.
Return a canonical plan revision for host validation and human review. Do not
implement the task during research or planning. Plan presentation is selected by
the harness and is independent of this procedure.
